# Demo video script (about 3–5 minutes)

Record this yourself after starting the application. Do not claim a feature worked unless you demonstrate it live.

1. **Introduction (20 sec):** “This is a salary management app for an HR Manager. It uses Java/Spring Boot, Angular and SQLite.”
2. **Show dashboard (30 sec):** Point out total employees and salary summary grouped by currency. Explain why currencies are not combined.
3. **Show employee list (40 sec):** Search by name or employee code. Filter by country and department.
4. **Show pagination (20 sec):** Move to another page and explain the API limits page size.
5. **Show employee salary (30 sec):** Open a record and explain department, country, title, currency and salary.
6. **Update salary (30 sec):** Change a sample employee's salary and save. If validation is implemented, show rejection of a negative amount.
7. **API and tests (40 sec):** Show `/api/health` and briefly show the backend test command/result in the terminal.
8. **Close (20 sec):** Mention synthetic 10,000-record seed data, automated tests and Docker Compose.

Avoid showing personal data or secrets. This project uses fictional data only.
